# 사자는 봉사를 좋아해

> 봉사활동 정보를 한눈에 확인하고, 참여하고, 리워드까지 받을 수 있는 봉사 플랫폼

---

## 📌 프로젝트 소개

봉사활동 정보를 검색하고, 북마크로 저장하며, 봉사 참여 후 리워드 포인트를 적립해 샵에서 사용할 수 있는 봉사활동 통합 플랫폼입니다.

---

## 🛠 기술 스택

### Backend

| 기술            | 버전  |
| --------------- | ----- |
| Java            | 17    |
| Spring Boot     | 3.3.5 |
| Spring Security | 6.x   |
| Spring Data JPA | 3.x   |
| MySQL           | 8.x   |
| Lombok          | 1.18.x|

### Frontend

| 기술             | 버전   |
| ---------------- | ------ |
| React            | 18.3.1 |
| React Router DOM | 6.26.2 |
| React Toastify   | 11.0.0 |
| Axios            | 1.7.7  |

### 인증

- 네이버 OAuth2 소셜 로그인
- Spring Security 기반 세션 인증

---

## ✨ 주요 기능

| 기능             | 설명                                          |
| ---------------- | --------------------------------------------- |
| 📋 봉사활동 목록 | 봉사활동 전체 목록 조회 및 페이지네이션       |
| 🔍 검색          | 키워드 기반 봉사활동 검색                     |
| 📄 상세 조회     | 봉사활동 상세 정보 (장소, 기간, 모집 인원 등) |
| 🔖 북마크        | 관심 봉사활동 저장 및 관리                    |
| 💬 댓글          | 봉사활동 게시글에 댓글 작성                   |
| 🏅 봉사 인증     | 봉사 참여 인증 등록                           |
| 🎁 리워드 샵     | 포인트로 상품 구매                            |
| 📍 위치 정보     | 카카오 역지오코딩 기반 위치 표시              |
| 🔐 소셜 로그인   | 네이버 로그인 연동                            |
